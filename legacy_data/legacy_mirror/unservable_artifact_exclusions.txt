# File types the archive can never serve, stripped from the capture itself.
#
# One glob per line, matched against a file's path relative to the served root
# and against its bare name, '#' comments and blank lines ignored. A pattern
# here is applied by the strip pass at the end of every crawl, and over a
# finished tree with --strip-unservable-only.
#
# The capture holds exactly what the archive serves. The strip pass removes
# everything here AND every file the publisher would not upload (its served
# types, minus its own exclusion list), so a file is served, held privately in
# IFPA custody, or gone. A group file worth keeping but not serving is ruled to
# custody before the strip runs; nothing is "captured but not served".
#
# What this list adds on its own is the floor that holds even if the
# publisher's declarations change: code of every kind, and types that only ever
# meant something to the old server.
#
# Removing a pattern does not bring anything back. The strip deletes, and the
# dead-link pass that follows it rewrites the pages that pointed at what it
# removed. Recovering a stripped file means re-capturing it.

# Code of every kind. The archive is static pages and media and runs nothing:
# every script is stripped from every page at capture. A standalone script, a
# Flash movie, a browser behaviour file, a macro-enabled Office file or a
# server program is code whose only purpose is to run, so the capture keeps
# none, exactly as the published archive serves none. The ones a capture has
# held: the JavaScript libraries the WordPress microsites referenced, Flash
# movies, an Internet Explorer behaviour file and a macro-enabled Excel
# judging template.
