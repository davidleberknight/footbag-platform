# Governance

This project is developed under the auspices of the International Footbag Players Association (IFPA). The code is licensed under Apache 2.0 ([LICENSE](LICENSE)); IFPA names and marks are not ([TRADEMARKS.md](TRADEMARKS.md)).

## Who decides

- **Technical matters:** the maintainer, David Leberknight ([@davidleberknight](https://github.com/davidleberknight)), IFPA CTO. This covers code, architecture, schema, documentation, tooling, infrastructure, repository settings, and accepting pull requests.
- **IFPA matters:** the IFPA Secretary. This covers IFPA policy, competition rules, official records and rankings, membership, and communications in IFPA's name, including use of IFPA branding.
- **IFPA Board vote:** required by the [IFPA bylaws](ifpa/BYLAWS.md) only for where IFPA funds are held, membership dues and levels (with membership ratification), and election timing.

## Changes that touch IFPA matters

A pull request that changes what the platform states or enforces as IFPA policy, rules, records, or membership terms is merged only after the IFPA Secretary approves it, or after a Board vote where the bylaws require one. The pull request records who approved and when.

## Repository

The repository is held on the maintainer's GitHub account, and the maintainer holds its administrative rights.
